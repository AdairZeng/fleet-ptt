## 待解除的实现阻塞

- **#33 灵矽联调**：需要配置公网 MCP Streamable HTTP 端点、私有 MCP 请求头与智能体关联；真实设备会话需验证平台身份头、工具选择、音频格式、TTS 和动作回执。
- **#35 灵矽云端唤醒**：当前按指令键采集；持续云端监听、连续说法、对讲中打断与回声处理尚未完成。
- **#30 采集共享**：灵矽负责唤醒和指令音频；是否能同时供 RTN 和灵矽编码使用，仍需明确输入与真实 SDK 音轨行为，未实现共享采集，不据类型声明宣称验证完成。
- **#34 跨 MCP 会话幂等**：同一 MCP 会话内按 JSON-RPC ID 复用请求结果；跨 MCP 会话重试需要进一步明确稳定请求标识及平台重试规则。灵矽会话 ID、Mcp-Session-Id 和设备 action_id 不能代替业务请求 ID。
- **#29/#31/#36 语音闭环**：首次语音设置、处理/确认/TTS 状态联动和端到端验收依赖上述能力。当前浏览器可用屏幕兜底操作；硬件凭证预配另行实现。

以上 Issue 保持未完成。用户统一验收前不将编译通过或 PR 合并视为运行时验收通过。

## 执行前准备

1. 配置独立测试数据库、SESSION_SECRET 和七牛 RTN 凭证。使用 HTTPS 或 localhost。
2. 准备两个独立浏览器配置文件/设备、麦克风及耳机，避免把两个标签页当作两个设备。
3. 配置已授权灵矽设备映射和测试服务，确认设备协议版本、上行编码/采样率/帧长及 TTS 播放结束信号。
4. 配置灵矽 API Key、智能体 ID、独立 MCP Token 和公网隧道，将私有云 MCP 关联到“小路”。按下 3D 原型电源键，验证开机检查/自动绑定、指令键采集、MCP 工具调用与 TTS；持续唤醒单独验收。
5. 使用按当前结构初始化的隔离数据库进行验收。
